Back-and-forth workspace toggle (deferred Tier 2.4)

Location
ROADMAP Tier 2.4
Source / Link
GlazeWM v3 config (general.toggle_workspace_on_refocus)
Description

GlazeWM's toggle_workspace_on_refocus is a top-10 muscle-memory feature: re-pressing the current workspace's key flips to the previous one. We deferred it (Tier 2.4) because the COM desktop machinery is undocumented — but our current_guid temp-probe already solves the read side; we only need 'previous desktop id' tracking plus the Ctrl+Win+number pass-through we already forward.

Recommended fix

Track last two desktop GUIDs on every cloak/uncloak WinEvent (already flowing); hotkey sends Ctrl+Win+prev-digit pass-through or COM move. Re-evaluate now that the COM-per-call pattern is proven stable.
